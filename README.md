# 🌾 Krishi-Sahayak | AI & Web Agricultural Platform

## 📌 Overview

Krishi Sahayak is an AI-powered web application designed to assist farmers and users with smart agricultural insights. It provides recommendations and predictions using machine learning models integrated with a Flask backend.

---

## 🚀 Features

* 🌱 Crop recommendation system
* 📊 Insurance prediction model
* 🤖 AI-based decision support
* 🌐 User-friendly web interface
* ⚡ Fast backend using Flask

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

```
git clone https://github.com/Sanika123-art/KrishisahayakAI-based-.git
cd KrishisahayakAI-based-
```

### 2️⃣ Create virtual environment

```
python -m venv env
```

### 3️⃣ Activate environment

* Windows:

```
env\Scripts\activate
```

### 4️⃣ Install dependencies

```
pip install -r requirements.txt
```

### 5️⃣ Run the app

```
python app.py
```
